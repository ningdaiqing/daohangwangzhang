# NavHub · 启动说明（报错排查版）

## 🚀 正常流程

1. 双击 `启动服务.bat`
2. 窗口里逐步显示 ✅
3. 看到 `访问: http://localhost:3000`
4. 浏览器访问该地址

## 🔍 报错对照表（窗口里看到这些怎么办）

| 窗口显示 | 原因 | 解决 |
|----------|------|------|
| `未检测到 Node.js` | 没装 Node | 安装 Node 18+：https://nodejs.org/zh-cn/ |
| `端口 3000 已被占用` | 已有 next 在跑 / 别的占着 | 关闭旧窗口，或 `taskkill /PID <pid> /F` |
| `依赖安装失败` | npm 拉包失败（GFW） | 检查 `.npmrc`，确保用了 npmmirror |
| `build 失败` | 编译报错 | 打开 `navhub-start.log` 滚到最后几行，贴给我 |
| `服务已停止` | next 进程退出 | 看 `navhub-start.log` 末尾，贴给我 |

## 📋 如果浏览器打不开但窗口显示 ✓ Ready

1. 浏览器地址栏直接输 **`http://127.0.0.1:3000`**（不是 localhost）
2. 关掉任何 VPN / 代理
3. PowerShell 执行：
   ```powershell
   netstat -ano | findstr :3000
   ```
   应该看到 `LISTENING`。如果没看到 = 服务没起。

## 🆘 启动器会写日志

每次启动都写到 **`navhub-start.log`**，报错时把这个文件发给我，我能秒看原因。

## 🛑 停止服务

在服务窗口里按 **Ctrl + C**

或者 PowerShell：
```powershell
taskkill /F /IM node.exe
```
（注意：这会杀掉所有 node 进程，包括别的项目，慎用）
